# Тренажёр по экологии

Бесплатный веб-тренажёр для подготовки к тестированию i-exam по экологии. Работает в браузере на телефоне и компьютере, без регистрации и без сервера.

## Что есть

- 106 вопросов по 13 темам: биосфера, экологические факторы, глобальные экологические проблемы, антропогенное воздействие на окружающую среду
- Типы заданий как на i-exam: один ответ, несколько ответов, соответствие, последовательность
- **Тренировка** с пояснением после каждого ответа
- **Работа над ошибками** по вопросам, в которых последний ответ был неверным
- **Экзамен** на 20 или 30 вопросов с таймером (90 секунд на вопрос) и разбором в конце
- Прогресс по каждой теме. Хранится в браузере (`localStorage`) и никуда не отправляется

Вопросы составлены по стандартному вузовскому курсу экологии. Это не задания из базы i-exam.

## Публикация на GitHub Pages

1. Откройте **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
3. Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/<имя-репозитория>/`.

## Как добавить вопросы

Весь сайт находится в одном файле `index.html`. Вопросы лежат в объекте `B`, сгруппированные по кодам тем (`b1`, `g2`, `a5` и т. д.). Список разделов и тем задаёт массив `SECTIONS`. Тема без вопросов показывается с пометкой «скоро».

```js
// один ответ: верный вариант всегда первый, при показе варианты перемешиваются
{k:'one', q:'Текст вопроса', o:['верный','неверный','неверный'], e:'Пояснение'}

// несколько ответов: a — номера верных вариантов (с нуля)
{k:'many', q:'...', o:['a','b','c','d'], a:[0,2], e:'...'}

// соответствие: p — пары [левое, правое], x — лишние варианты справа (необязательно)
{k:'match', q:'...', p:[['Термин 1','определение 1'],['Термин 2','определение 2']], x:['лишнее'], e:'...'}

// последовательность: o — элементы в правильном порядке
{k:'order', q:'...', o:['первый','второй','третий'], e:'...'}
```

Новые вопросы добавляйте в конец списка темы: прогресс привязан к порядковому номеру вопроса внутри темы.
